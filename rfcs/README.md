# AROP RFCs

RFCs record proposed normative changes to the protocol, conformance requirements, compatibility policy, security model, or public governance.

An RFC moves through:

```text
draft -> review -> accepted | rejected | withdrawn -> implemented
```

Acceptance requires two Maintainer approvals. An accepted RFC is not implemented until the normative Schema, examples, tests, and affected documentation land together.

Use `template.md`, assign the next four-digit number, and name the file `NNNN-short-title.md`.
